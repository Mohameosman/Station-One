# Station One V4.3 Pixel Perfect

هذه النسخة مبنية على التصميم المعتمد نفسه وبنفس أبعاد الصورة المرجعية 1664×928.

## لماذا هذه النسخة مطابقة؟
- تستخدم التصميم المعتمد كطبقة واجهة أساسية Pixel Perfect.
- جميع مناطق التفاعل موضوعة فوق التصميم بالنسب نفسها.
- البحث، التنبيهات، القائمة، تكبير الخريطة، زر التعيين، وتتبع الرحلات تعمل.
- تتكيف الواجهة مع عرض الشاشة مع الحفاظ على النسب الأصلية.
